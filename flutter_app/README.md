# 3D Anatomy Atlas — Flutter

Native Flutter mobile application for the Connacri/3d-anatomy atlas.

The viewer uses interactive_3d with Google Filament on Android and SceneKit on iOS. It provides native GLB/GLTF rendering, rotate/pan/zoom gestures, entity selection/picking, runtime PBR material overrides, visibility groups and camera zoom.

The anatomy GLB files stay in the main repository and are downloaded on demand from public GitHub raw assets, avoiding duplication of the roughly 47 MB model set.

## Run

From flutter_app:

    flutter pub get
    flutter run

The Android/iOS platform folders are generated by Flutter tooling/CI.

## Data

The app consumes:

- public/models/*.glb
- public/data/systems.json
- public/data/definitions.json

## Identity mapping

The GLB exporter stores the authoritative Z-Anatomy identifier in extras.za_name while the native plugin exposes the GLTF node name. The app normalizes node names against systems.json to recover the canonical anatomical label.

## Transparency

The opacity control sends RGBA material overrides. Actual alpha blending depends on the blend/material configuration authored in the GLB/native renderer; native visibility and PBR material controls are available.
